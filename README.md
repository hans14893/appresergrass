# App Reserva Grass

App móvil Expo/React Native para clientes, personal autorizado y administrador.

## Ejecutar

```powershell
npm install
npm start
```

Por defecto consume:

- API: `http://localhost:8080/api`
- WebSocket: `http://localhost:8080/ws`

Si pruebas desde un celular físico, cambia esos valores en `app.json` por la IP de tu PC en la red local.
